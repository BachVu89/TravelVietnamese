# Project instructions

- This repository is a fresh Unity 6 URP painterly offline mobile game. Do not restore or copy legacy implementations/assets from Git history.
- Keep production source in Assets/VietTrail. Core rules stay independent of UnityEngine.
- Use the shared painterly palette and shaders. Avoid PBR texture packs, paid dependencies, online gameplay services, and unverified package additions.
- Commit .meta files with assets. Keep scene/script GUID references stable.
- Clearly distinguish planned provinces/islands from playable routes. Do not describe illustrative terrain as surveyed or DEM-based.
- Run structural, Core, and syntax checks where available. Only an actual Unity Editor run can establish engine compile, rendering, physics, and build acceptance.
- Never claim an APK, device performance, geographic completeness, or reference-image fidelity from source checks alone.
