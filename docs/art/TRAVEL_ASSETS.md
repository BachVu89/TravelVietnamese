# Original touring motorcycle and explorer visuals

`SM_TouringMotorbike`, `SM_RiderSeated` and `SM_ExplorerStanding` are original Blender geometry generated by `scripts/art/create-unity-travel-characters.py`. No branded model, scan, external library or reference-image texture is included.

- Bike: 6,008 triangles; spoked wheels, curved mudguards, frame, engine ribs, handlebars/mirrors, lamps, seat and rear luggage. Static visual only; physics remains the existing arcade CharacterController.
- Seated rider / standing explorer: 3,116 triangles each, clothed limbs, helmet/visor, boots and backpack. Static poses, no skeleton/skin animation or photoreal face. The neck gap found in the first Blender preview was corrected before final export; heights are 1.66 m (seated visual extent) / 1.75 m (standing).
- FBX, material slots, dimensions and SHA256: `unity/TravelVietnamese/Assets/TravelVietnamese/Art/TravelSource/provenance.json`.
- Authoring source: `art-source/unity/TravelSource/TravelCharacters.blend`, kept outside Unity `Assets` so opening the project does not require Blender installation.
- Forward convention: Blender −Y, exported FBX −Z forward/Y up, metric units. Check actual Unity orientation/scale before gameplay acceptance. Matching Blender readback does not prove Unity conversion.

Recreate from repository root using `blender --background --factory-startup --python scripts/art/create-unity-travel-characters.py`. This overwrites these generated source/FBX/preview outputs; preserve artist edits first. FBX timestamps may change checksums on regeneration.

[Preview](travel-characters-preview.png) is an actual CPU Cycles render of the authored assets, not a Unity screenshot. Root inspected the final output and the helmet/neck connection. The shape is more detailed than the previous block primitive placeholders, but remains stylized. It does not meet the original photoreal reference.
